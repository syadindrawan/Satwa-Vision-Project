Tentang Proyek

Dibangun sebagai studi kasus transfer learning yang ringkas.

SatwaVision lahir dari pertanyaan sederhana: seberapa akurat model yang sudah dilatih pada jutaan gambar umum (ImageNet) bila diarahkan ulang untuk mengenali sepuluh spesies spesifik? Proyek ini membandingkan foto anjing, ayam, domba, gajah, kucing, kuda, kupu-kupu, laba-laba, sapi, dan tupai, lalu menyaring karakter visual yang membedakan tiap kelas - bentuk telinga, sayap, corak bulu, hingga jumlah kaki.

Model ini menggunakan MobileNetV2 sebagai fondasi, dengan bobot dari ImageNet yang sudah di - pretrained sebelumnya, kemudian di finetuning pada dataset sepuluh kelas ini melalui dua tahap pelatihan bertingkat.

Cara Kerja

Empat lapis proses, dari piksel sampai prediksi.

01 · INPUT

Upload ke server

Foto dikirim dari browser ke server menggunakan Flask.

02 · PRAPROSES

Resize & normalisasi

Gambar diubah ke 224 x 224px agar sesuai dengan skala MobileNetV2 yang sudah dibangun di dalam model.

03 · FINE-TUNING

MobileNetV2 fine-tuned

Backbone pretrained ImageNet, dilatih ulang dua tahap khusus untuk sepuluh kelas hewan ini.

04 · RUNTIME

Inference di server

Model dijalankan oleh Flask, Lalu menghasilakan prediksi.
